# implementNotion

A simple Notion-style note-taking web application built with HTML, CSS, and JavaScript.

The app allows users to create, edit, organize, search, and preview notes directly in the browser. Notes are saved locally using `localStorage`, so the app works without a backend server.

## Features

- Create and delete notes
- Create, rename, and delete folders
- Organize notes inside folders
- Pin important notes
- Search notes by title or content
- Sort notes by title or last updated date
- Markdown editor with live preview
- Formatting toolbar:
  - Bold
  - Italic
  - Underline
  - Text color
  - Heading 1
  - Heading 2
  - Bullet list
  - Numbered list
- Dark mode
- Export notes as JSON
- Import notes from JSON
- Responsive sidebar for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser `localStorage`
